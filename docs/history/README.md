# 归档说明

- CONVERSATION.md：可读的对话正文。
- conversation.json：相同正文的结构化版本。
- operations.jsonl：范围内的工具调用及会话保存的返回结果（网页查询、文件操作、环境和 ADB 检查等）。部分工具返回本身已截断，不是完整网络流量或终端录屏。
- 操作调用为记录用途，不应复制后自动执行；其中包含历史失败操作。
- 不复制整个原始会话文件，以免带入内部指令和会话元数据。
- 真实本机配置 config/local.json 保留在电脑上，不提交；版本库包含可编辑的 local.example.json。
- 本次归档/提交/推送过程另外记录于 ../GIT-PUBLISH.md。归档为固定快照，不自动追加后续聊天。
- 项目包含本机路径、用户发言及工具输出；由用户明确要求保存并推送到指定仓库，仓库可见性决定谁能阅读。
